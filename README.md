# iOS马甲包上架/苹果马甲包

iOS审核一直都是比较难搞的事情，特别是马甲包最难搞的莫过于4.3和2.3.1，只要细节处理好，基本上都可以上架 100%通过，我们主要是社交应用类，以下是总结出来的经验

注意事项 

1.注意网络ip，每个包上传的时候不要用同一个网络

2.注意开发上传ipa的硬件设备，每个包不要用同一台电脑上传

3.注意测试设备不要多个开发者账号关联同一个测试设备

4.代码处理干净一点

5.一级页面经量要有特色一点，最起码不要一摸一样

6.经量不要一次性提交完成，分批次更新最佳，一次性提交容易4.3

7.应用类型，关键字，名字商店截图把控一下尺度避免2.3.1 出现金币字样也容易2.3.1
